# ☕ Bengaluru Café

### A Modern & Elegant Café Business Website

A modern, responsive café website designed to create a premium online presence for a Bengaluru-based café.

The website focuses on elegant visual design, simple navigation, responsive layouts, and presenting a café's menu, atmosphere, location, and contact information in a professional way.

The goal of this project was to create a professional website that a real café or restaurant could use to establish its online presence.

The design emphasizes:

- Brand presentation
- Visual appeal
- Easy navigation
- Menu accessibility
- Customer engagement
- Mobile responsiveness

## 📱 Responsive Design

The website is designed to work across different screen sizes:

- 💻 Desktop
- 📱 Mobile
- 📟 Tablet

The layout, typography, navigation and content adapt to provide a consistent experience across devices.

---

## 🎨 Design Approach

The design uses a warm café-inspired visual style with:

- Elegant typography
- Large visual imagery
- Clean spacing
- Minimal navigation
- Strong visual hierarchy
- Modern call-to-action buttons

The objective was to create a website that feels **premium, welcoming and easy to use**.
